# The prototype site

`clip-factory.html` is a prototype of the PRODUCT — what an operator sees —
as distinct from `web/`, which is the local control surface that actually
drives the pipeline. Published as an Artifact so it can be opened and shared
without this machine.

## It is built from one real run

Every figure comes from `jobs/fns-2905408276`: 50 candidate windows screened,
10 buildable, 8 kept after topic dedup, 4 delivered. The subjects, muted
shares, cut rates and refusal reasons are that run's `screened.json`. The
clip posters are frames from the delivered mp4s and the spec fields are the
real `clips/fns-*.json`. Nothing on the page is invented, and the only thing
simulated is the stage rail's replay — which shows STATE and no durations,
because the per-stage timings were never measured.

## It uses the clips' own design system

Tokens are `vendor/remotion-clip08/src/theme.tsx`: Polymarket `#2E5CFF`,
`#5C80FF` where it has to hold against dark, pure white, `RADIUS = 0`, Inter
for UI and Source Serif 4 for the one editorial line. The site and the clips
agree because they read the same decisions.

Two house rules carry it:

* **Nothing coloured is ever a number.** The blue is a key bar, a funnel
  fill, a rule — structure. Every figure is ink or white. This is also why
  the funnel labels sit OUTSIDE the bars: a label inside the fill makes the
  colour carry data, and it clips to nothing on a short bar.
* **The accent never touches a photograph.** The clip posters sit on the
  neutral band, never on blue.

## Rebuilding it

    python3 build.py        # concatenates the parts and inlines the data

The page is assembled from `head.html`, `style2.html`, `style3.html`,
`body.html` and `script.js` so each piece stays editable; `build.py` writes
`clip-factory.html`. The data is regenerated by `data.py`.
